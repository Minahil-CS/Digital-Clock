# ⚡ Cyber Clock — Interactive World Clock Dashboard
A modern, responsive, real-time digital clock and world clock dashboard built with pure HTML, CSS, and vanilla JavaScript. Features glassmorphism UI, interactive audio toggles, live multi-timezone tracking, dynamic SVG seconds visualizers, and customizable ambient neon color schemes.

---
## 🌟 Key Features

- ⏱️ **12-Hour Precision Engine:** Dynamic 12-hour local clock with high-visibility AM/PM badges and tabular digits preventing horizontal text jitter.
- 🌍 **Live World Clocks:** Real-time synchronized time tracking for key global regions:
  - 🇵🇰 Pakistan Standard Time (PKT)
  - 🇬🇧 London / Greenwich Mean Time (GMT/BST)
  - 🇺🇸 New York / Eastern Time (EST/EDT)
  - 🇯🇵 Tokyo / Japan Standard Time (JST)
  - 🇦🇪 Dubai / Gulf Standard Time (GST)
- 🎨 **Dynamic Theme Presets:** Instant real-time color scheme switcher:
  - 🪐 **Cyber Neon** (Default Deep Cyan & Purple)
  - 🌅 **Sunset Gold** (Warm Amber & Gold Accent)
  - 🟢 **Matrix Green** (Retro Terminal Aesthetic)
  - 🌌 **Midnight Aurora** (Cool Ice Blue & Deep Navy)
- ⭕ **Radial Seconds Visualizer:** Smooth SVG circular stroke dynamically updating in real-time with the current second count.
- 🔊 **Synthesized Tick Sound:** Built-in Web Audio API sound generator delivering crisp, clean mechanical tick feedback (toggleable).
- 📱 **Fully Responsive:** Fluid CSS grid and flexbox layout optimized for desktops, tablets, and mobile screens.

---

## 🛠️ Built With

* **HTML5** — Semantic structure & SVG graphics engine.
* **CSS3** — Custom properties (variables), Flexbox, CSS Grid, animations, and Glassmorphism backdrop-filters.
* **Vanilla JavaScript (ES6+)** — Asynchronous `setInterval` tick timing, `Intl.DateTimeFormat` for reliable cross-region timezone resolution, and Web Audio API context synthesis.
* **Google Fonts** — `JetBrains Mono` & `Inter`.
